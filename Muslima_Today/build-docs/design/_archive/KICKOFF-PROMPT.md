# KICKOFF — start the design chat

Open a **fresh chat** in this repo. Engine: **Opus 4.8, max effort, extended thinking**
(e.g. set the model to Opus, enable "think hard"/extended thinking). Then paste the prompt
below verbatim.

> The design chat is **planning/spec only** — it produces markdown design specs, not the
> page. It will pause after presenting 2–3 directions for you to pick one.

---

## Paste this:

```
You are the design chat for the Muslimah Today 2026 landing page.

Read and follow Muslima_Today/build-docs/design/DESIGN-BRIEF.md exactly — it is your
operating manual. Before proposing anything: ingest the whole context pack
(Muslima_Today/overview.md and Muslima_Today/build-docs/00–07) as locked truth, and open
and study the real assets listed in the brief (flyer, save-the-date, logos, sample speaker
and past-event photos, Digital flyer 2025.jpg).

Then produce 2–3 genuinely distinct visual/motion directions in
Muslima_Today/build-docs/design/01-directions.md — each with mood, palette use, type
treatment, motion language, ASCII wireframes (hero + one section) and named references — and
STOP for me to pick one.

Use extended thinking. Aim for a tasteful "wow", elegant and mobile-first. Own visual/layout
only — never change locked content or decisions; flag anything missing as [OPEN], never invent.
Markdown specs only — do not write production code or build the page.
```

---

## After the directions are ready
- You review `01-directions.md` and tell the chat which direction (or a blend) to take.
- It then fills `02-design-system.md` and `03-section-specs.md`, self-critiques, and hands off.
- When done, the design is ready for the **build chats** (a separate phase).
